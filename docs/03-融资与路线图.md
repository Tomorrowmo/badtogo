## 3. 种子轮 Pitch 提纲（一页纸逻辑）

1. **问题**：人人都有"当下很气/很崩"的瞬间，但冥想 App 太慢、线下愤怒屋太贵，市面"发泄玩具"还可能让你更气（有研究为证）。
2. **方案**：BadToGo = 60 秒安全发泄 + 循证平复，并让你**看见情绪分下降**。
3. **为什么有效（差异化）**：唯一把"宣泄 + 平复"做成闭环的产品；用前后打分自证疗效。
4. **市场**：数字心理健康数百亿美元、双位数增长；切"急性情绪急救"未被满足的瞬间。
5. **商业模式**：C 端 Freemium 订阅 + B2B/EAP 席位订阅。
6. **护城河**：循证闭环 + 隐私本地优先 + 情绪数据资产 + 疗效度量。
7. **进展**：可用产品 + 早期有效性数据（情绪分下降率）。
8. **要多少钱、干什么**：种子轮用于 PWA→App 化、增长冷启动、B2B 试点与基础合规。

## 4. 关键财务假设（量级，非预测）

- ARPPU：¥80–150/年；付费率目标 3–5%。
- CAC：早期靠内容自传播（发泄前后对比视频 + 分享卡）压低获客成本。
- LTV/CAC：订阅模型下，只要次周留存 > 25%、付费转化达标，LTV/CAC 可进入健康区间（> 3）。
- B2B：席位单价显著高于 C 端，1 个中型企业客户即可覆盖一支小团队的运营。

---

## 5. 合规与伦理（投资人尽调必问）

- 明确"非医疗、不诊断"定位 + 危机求助引导（已在产品"关于"页落地）。
- 默认不收集 PII；云功能走端到端加密、用户显式开启。
- 这套设计同时是**风控**与**B2B 销售卖点**。
