# BadToGo · 产品设计与心理学依据
> 角色：产品经理 / 心理学顾问 / 体验设计  
> 原则：每个功能都回答"它治什么、有什么证据、怎么做"。

---

## 1. 核心体验闭环（产品的灵魂）

```
①  CHECK-IN 命名情绪        →  ②  VENT 宣泄        →  ③  BREATHE 平复        →  ④  REFLECT 复盘
   "我现在是什么情绪？几分？"     "砸/撕/吼/捶，发出去"     "盒式呼吸把唤起降下来"      "现在几分？看见自己变好"
```

**为什么是这个顺序（作证）**
- 先 check-in：情绪粒度研究表明，**先命名情绪**就已经开始调节（"name it to tame it"，Lieberman 等的情感标注研究）。同时拿到"发泄前分数"作为基线。
- 中间 VENT：满足"我现在就想发泄"的真实冲动，给情绪一个安全出口（表达性书写、物理丢弃负面想法的证据见 `01` 文档）。
- 必接 BREATHE：**这是产品的安全阀**。Bushman(2002) 证明只发泄会抬高愤怒，所以发泄后必须下调唤起，否则产品有害。这一步把 BadToGo 从"玩具"变成"工具"。
- 收尾 REFLECT：再次打分，前后对比 → 用户**亲眼看到情绪分下降**，形成疗效感与回访动机。

> 设计红线：**永远不让用户停在"刚发泄完、唤起最高"的状态**。VENT 结束默认引导进 BREATHE。

## 2. 四种宣泄模式（VENT）

| 模式 | 交互 | 治什么 | 心理学依据 |
|---|---|---|---|
| **撕掉 Shred** | 输入烦恼文字 → 撕碎/烧毁/扔进黑洞，文字灰飞烟灭 | 反刍、说不出口的话 | 表达性书写（Pennebaker）；物理丢弃负面想法降低其影响（Briñol et al., 2013） |
| **砸碎 Smash** | 点击/拖拽砸碎盘子玻璃，碎片+音效+震动反馈 | 急性愤怒、烦躁 | 提供安全、可控、无伤害的破坏出口；强反馈带来掌控感 |
| **吼出来 Scream** | 麦克风采集，把你的吼声实时可视化成冲击波/震碎屏幕 | 憋屈、压抑 | 发声释放 + 即时视觉反馈强化"我把它发出去了" |
| **捶打 Punch** | 连击出气筒，combo 计数与节奏反馈 | 烦躁、需要动起来 | 身体动作宣泄 + 节奏感；为下一步呼吸做生理过渡 |

**通用设计原则**
- 每个模式都有**强即时反馈**（视觉碎裂、音效、可选震动），这是"解压感"的来源。
- 音效用 **Web Audio 实时合成**，不依赖任何二进制资源 → 完全离线、零安装、包体小。
- 隐私：撕掉模式的文字**只在内存中**，销毁动画后即丢弃，绝不落盘上传（隐私即卖点）。

## 3. 平复模式（BREATHE）

- **盒式呼吸 4-4-4-4**：吸 4 秒 → 屏 4 秒 → 呼 4 秒 → 屏 4 秒，圆环随呼吸缩放，文字+节奏引导。
- 备选**延长呼气**（吸 4 / 呼 6），延长呼气强化副交感、更快平静。
- 依据：慢节奏、呼气延长的呼吸可降低交感唤起与主观压力（呼吸调节交感/副交感平衡的生理学共识）。
- 默认 4 个循环（约 1 分钟），可继续。

---

## 4. CHECK-IN / REFLECT（情绪打分）

- 选一个情绪词（愤怒/焦虑/难过/烦躁/委屈/压力大…）+ 0–10 强度滑杆。
- 发泄+平复后再打一次分，展示 **前 → 后** 对比与下降幅度。
- 所有记录存 **localStorage**（本地、可一键清空），形成"情绪趋势"曲线。
- 依据：情绪粒度（Barrett）+ 自我监测（self-monitoring）是循证情绪管理的基础组件；前后对比提供即时正反馈。

## 5. 信息架构 / 界面流

```
首页（Home）
 ├─ 大标题 + 今日心情/连续天数
 ├─ [开始] → CHECK-IN
 │        → 选择 VENT 模式（撕/砸/吼/捶）
 │        → BREATHE
 │        → REFLECT（前后对比）→ 分享卡（可选）
 ├─ 趋势（Trends）：情绪曲线、闭环完成数、下降率
 └─ 关于/隐私/危机求助
```

- 单页应用（SPA），全程无需注册、无网络请求。
- 移动优先（竖屏手势友好），同时桌面可用。

---

## 6. 伦理与安全（不可妥协）

- 明确声明：**BadToGo 不是医疗/诊断工具，不替代专业心理治疗**。
- 内置**危机求助引导**：当用户多次记录极端低落，或在"关于"页提供求助热线指引（中国心理援助热线、国际可替换），并提示"如有自伤/伤人念头请立即联系专业帮助"。
- 不收集可识别个人信息；文字宣泄内容不落盘、不上传。

---

## 7. 视觉与品牌语言

- 调性：**深色、克制、有呼吸感**，不卖惨也不浮夸。从"压抑的暗"过渡到"释然的亮"。
- 主色：深空底 + 情绪暖色强调（宣泄时偏红橙、平复时转青蓝），用颜色叙事情绪的"由激到静"。
- 动效：碎裂、消散、缩放呼吸——动效本身就是疗愈语言。
- 字体：系统无衬线，保证零安装与跨平台一致。
