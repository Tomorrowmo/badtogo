```
mental-health  stress-relief  emotional-wellness  anger-management
mindfulness  breathing-exercises  self-care  wellbeing  mood-tracker
pwa  offline-first  privacy-first  no-dependencies
```

> 这些词覆盖了「心理健康 / 减压 / 情绪」需求人群，和「纯前端 / PWA / 零依赖」技术人群两类搜索者。

## 3. Social Preview 社交预览图（可选，但强烈建议）

仓库 Settings → 顶部 "Social preview" → 上传一张 1280×640 图。
- 最省事：把应用里"生成分享卡"导出的图，或首页截图，做成 1280×640。
- 有预览图的仓库在被分享到微信/X/Discord 时点击率显著更高。

## 4. 还能进一步提升曝光的动作（按性价比排序）

1. **加 Live Demo 徽章/链接**：README 顶部已放线上体验地址，确保可点。
2. **写好首条 Release**：打个 `v1.1.0` tag 发 Release，附"先发泄后平复"的一句话亮点 + 截图。
3. **截图/GIF 进 README**：录一段"发泄→呼吸→情绪分从 8 降到 3"的 GIF 放 README 顶部——这是本项目最有说服力的画面。
4. **提交到清单**：把项目提到 `awesome-mental-health`、`awesome-pwa` 等 awesome 列表（提 PR）。
5. **发一条产品帖**：少数派 / V2EX / Reddit r/SideProject / Product Hunt，标题用"先发泄后平复"的反直觉点（单纯发泄反而更气，所以我做了平复闭环）。
